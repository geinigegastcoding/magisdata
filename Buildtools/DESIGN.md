# MagisData — design.md v1

## 0. Core Purpose

MagisData is not positioned as a generic web agency.

MagisData exists to create strategic digital infrastructure for ambitious businesses that want:

* visibility
* authority
* long-term scalability
* technological leverage
* search dominance
* future-proof systems

The brand should communicate:

> Calm strategic superiority.

Not loud superiority.

The visual system must feel:

* engineered
* intelligent
* premium
* precise
* modern
* warm enough to build trust
* restrained enough to signal authority

The identity system prioritizes:

1. High-ticket client attraction
2. Authority and trust
3. Strategic positioning
4. Lead generation
5. SEO + GEO + AEO optimization
6. Long-term scalability

# 2. Logo System

## 2.1 Logo Architecture

The MagisData logo system consists of 3 layers:

### A. Primary Lockup

Used for:

* website headers
* presentations
* documents
* business cards
* proposals
* dashboards

Structure:

* symbol + wordmark

---

### B. Standalone Symbol

Used for:

* favicon
* app icon
* social avatars
* watermarks
* loading states
* compact UI

The standalone symbol must remain recognizable at very small sizes.

---

### C. Emblem Variant

Used for:

* merchandise
* apparel
* embossed materials
* premium print applications
* packaging

The emblem should feel:

* architectural
* engineered
* symbolic
* restrained

NOT:

* medieval
* gaming-oriented
* mascot-like

---

## 2.2 Symbol Philosophy

The symbol represents:

* upward progression
* strategic structure
* engineered systems
* precision
* scalable infrastructure

The symbol should NEVER:

* use literal AI symbolism
* use brain icons
* use circuit imagery
* use mascots
* use literal animals

The symbol language is:

* geometric
* balanced
* angular with restraint
* symmetrical
* architectural

---

## 2.3 Logo Usage Rules

### Minimum Clear Space

Use at least:

* 1x symbol width around all sides

Never crowd the logo.

Whitespace increases premium perception.

---

### Incorrect Usage

Never:

* distort the logo
* over-glow the logo
* apply gradients excessively
* rotate the logo
* stretch proportions
* use low contrast backgrounds
* place on noisy textures
* use amber excessively

---

Purpose:

Purpose:

* borders

---

### Bone

HEX: #E9E8E6
Purpose:

* readability

---

### Amber

HEX: #FF8A00
Purpose:

* emphasis only
* CTA focus
* key highlights
* interaction moments
* premium accents

Amber should feel:

* deliberate
* valuable
* energetic
* intelligent

NOT:

* decorative
* playful
* loud

---

## 3.2 Color Ratios

Recommended ratio:

* 70% Graphite/Dark Neutrals
* 20% Bone/Light Space
* 8% Steel/Slate
* 2% Amber

The rarity of amber increases perceived value.

---

## 3.3 Color Psychology

* stability
* intelligence
* authority
* luxury
* strategic thinking

Amber communicates:

* energy
* strategic action
* warmth
* controlled innovation

# 4. Typography System

## 4.1 Typography Philosophy

Typography is one of the primary carriers of premium perception.

The typography system should feel:

* engineered
* intelligent
* calm
* spacious
* readable
* modern

Typography should NEVER feel:

* futuristic gimmicky
* over-stylized
* decorative
* compressed
* noisy

---

## 4.2 Primary Typeface

Primary:
Satoshi

Usage:

* headlines
* hero sections
* navigation
* strategic messaging
* key UI labels

Characteristics:

* geometric precision
* premium spacing
* calm authority

---

## 4.3 Secondary Typeface

Secondary:
Inter

Usage:

* body text
* UI text
* paragraphs
* dashboards
* informational content

Characteristics:

* readability
* scalability
* human balance

---

## 4.4 Typography Rules

### Headings

Should:

* breathe
* use generous spacing
* avoid visual clutter
* feel architectural

---

### Paragraphs

Optimize for:

* scanability
* SEO readability
* AI extraction clarity
* information hierarchy

---

### Tracking

Slightly increased tracking should be used in:

* uppercase text
* navigation
* labels
* premium headings

Avoid excessive letter spacing.

---

# 5. Spacing System

## 5.1 Philosophy

Whitespace communicates:

* confidence
* intelligence
* luxury
* control

* trust
* perceived quality

---

## 5.2 Grid System

* 8px spacing system

* 32
* 48

* 96
