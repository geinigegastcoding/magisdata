# MagisData V1

Production-ready Next.js website for MagisData, built as strategic digital infrastructure for premium positioning, SEO, GEO, AEO, AI retrieval, and lead generation.

## Commands

- `npm install`
- `npm run convert:assets`
- `npm run dev`
- `npm run build`

## Architecture

- `app/` App Router pages, metadata, sitemap, robots, and `llms.txt`
- `components/` reusable UI, layout, sections, schema renderer, and motion
- `content/` structured services, insights, case studies, FAQs, and page data
- `schemas/` JSON-LD graph builders
- `public/assets/` optimized WebP assets generated from `Buildtools/`
